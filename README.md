# RiseofGethering

ライズオブキングダム向けの集結スケジュール管理 Web アプリです。

## クイックスタート

```bash
npm install
cp .env.example .env.local
npm run dev
```

- React + TypeScript + Vite
- Tailwind CSS
- Firebase Firestore
